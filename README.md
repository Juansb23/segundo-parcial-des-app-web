Segundo Parcial Desarrollo de Apps Web.

Juan Sebastian Bayona Peñaranda - 0192611
Andres Felipe Carrascal Avendaño - 0192631

Este proyecto consiste en una aplicación web desarrollada con Vue.js 3 y Bootstrap CSS para la gestión de una cafetería. La aplicación cuenta con un sistema de inicio de sesión, un dashboard principal y un módulo de gestión de productos con operaciones CRUD simuladas utilizando LocalStorage y archivos JSON locales.

El proyecto fue construido de forma modular mediante componentes reutilizables, rutas dinámicas y un diseño responsivo, aplicando buenas prácticas de desarrollo web y trabajo colaborativo mediante GitHub.
